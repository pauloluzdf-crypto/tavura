# Tavurá v2.1 — River Experience
Iteração de teste baseada na v2 experimental.

Mudanças principais:
- seção Natureza → Tecnologia → Criatividade ~30% mais curta;
- rio contínuo e mais orgânico;
- transição visual para circuito dourado;
- nós eletrônicos no final do percurso;
- limites de largura para monitores ultrawide;
- correção da hierarquia da seção “Não vendemos...”;
- títulos menos gigantes e microtexto mais legível.

Suba todo o conteúdo do ZIP na raiz do repositório substituindo a v2 experimental.
O WhatsApp continua propositalmente desativado para o teste.
