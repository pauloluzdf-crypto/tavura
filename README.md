# Tavurá — Site v1.0
Protótipo estático para GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório.
2. Envie o conteúdo deste ZIP para a raiz (index.html deve ficar na raiz).
3. Abra Settings > Pages.
4. Em Source, escolha Deploy from a branch.
5. Branch `main`, pasta `/ (root)`.

## Antes da publicação oficial
- Edite `script.js` e troque `5500000000000` pelo WhatsApp Business, no formato 55DDDNUMERO.
- Quando o domínio estiver pronto, incluir URL canônica, og:url e og:image.
- Substituir a seção Projetos por cases reais.
- Adicionar Analytics/Meta Pixel quando as contas estiverem configuradas.
